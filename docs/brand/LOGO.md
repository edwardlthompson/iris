# Iris logo

Iris is a self-hosted phone remote for coding agents. The mark is an iris: a dark aperture with one bright slit, like an eye that is also a lens. It should read at 32px on a phone and in a Windows tray.

- Shape: circle, not a wordmark, for the app icon
- Color: charcoal `#1e1e1e`, iris violet `#7c6cf0`, a thin highlight `#d7d2ff`
- No letters inside the icon
- Flat, geometric, no photoreal eye, no gradients that turn muddy at small size

Wordmark, when used beside the icon: “Iris”, sentence case, geometric sans.
